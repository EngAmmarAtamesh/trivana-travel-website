# Trivana – Travel & Tourism Website

A modern, responsive travel and tourism website designed to help users explore destinations, discover travel packages, compare pricing, and plan their next journey.

## 📌 Project Overview

Trivana is a front-end travel website created as a team project. The website focuses on a clean, modern user experience with responsive layouts, destination discovery, travel packages, pricing, gallery content, FAQs, and contact information.

## ✨ Features

- Responsive navigation bar
- Hero section with travel-focused call to action
- Destination exploration
- Travel packages
- Pricing section
- Image gallery
- FAQ section
- Contact page
- Responsive design for desktop, tablet, and mobile
- Smooth scrolling and interactive UI elements
- Back-to-top functionality
- Reusable UI components and styling

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons
- Git & GitHub

## 🎯 Project Goal

The goal of Trivana is to provide users with a simple and visually engaging way to explore travel destinations and services while maintaining a responsive and user-friendly experience.

## 🚀 Running the Project

No build tools are required.

1. Clone the repository.
2. Open `index.html` in a browser.

For the best experience, run the project using **VS Code Live Server**.
